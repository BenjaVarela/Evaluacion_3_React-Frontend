# Declaración de uso de Inteligencia Artificial

## 1. IA usada
Se utilizó la herramienta de Inteligencia Artificial **Gemini**.

## 2. Modelo
Gemini 3.6 flash.

## 3. Prompts realizados
- "Revisa este código que es para habilitar el router para toda la aplicación, dime si está bien, si es el caso contrario dame el código corregido junto a los cambios que le hiciste."
- "Revisa que este todo correcto en mi archivo Proyectos.jsx"
- "Dame la estructura de Layout.jsx según el wireframe provisto"
- "Haz el layout sin div utilizando elementos semánticos"
- "Necesito que ocupes esta paleta de colores"
- "Agrega la imagen dentro del componente Inicio.jsx"

## 4. Outputs
- Verificación del enrutamiento inicial en `main.jsx`.
- Sugerencias de correcciones ortográficas y optimización del paso de props en `Proyectos.jsx` usando el operador spread (`...proj`).
- Generación de estructura HTML5 semántica (`header`, `nav`, `main`, `footer`) para `Layout.jsx`.
- Hoja de estilos `index.css` formateada con variables CSS según la paleta de colores especificada.
- Integración de rutas de imágenes importadas desde `src/assets/`.

## 5. Ajustes
- Se modificó la maqueta del layout para asegurar que no contuviera etiquetas `div` innecesarias y utilizara etiquetas HTML5 semánticas junto a un fragmento de React.
- Se mantuvieron y adaptaron los nombres de componentes y las clases CSS según la estructura del proyecto personal.
- Se ajustó el tamaño de la imagen del `hero` en el archivo CSS para mantener las proporciones visuales.

## 6. Reflexión crítica
El uso de la inteligencia artificial me sirvió bastante para resolver dudas rápidamente. Además, me ayudó a entender mejor cómo organizar la estructura de las páginas y cómo usar componentes reutilizables sin complicarme tanto. También fue muy útil para escribir los estilos CSS más rápido y adaptar la paleta de colores que quería usar. Por otro lado, me di cuenta de que no puedo copiar todo tal cual lo entrega la IA, porque siempre es necesario revisar el código, ajustarlo a la pauta del trabajo y probar que realmente funcione bien en el navegador. De igual forma el autocompletador integrado en VS code me ayudó a guiarme cuando me encontraba atascado con cosas que no recordaba. Aprendí mucho sobre React Router y a tener más control sobre mi propio proyecto.
